# BlockPlot

A decentralized land registry platform built on blockchain technology for secure, transparent, and tamper-proof property ownership management.

## Overview

BlockPlot is designed to modernize land registration by replacing traditional paper-based systems with a decentralized solution. The platform enables property owners, buyers, and government authorities to securely register, verify, and transfer land ownership records on-chain.

By leveraging blockchain technology, BlockPlot helps reduce fraud, eliminate duplicate ownership claims, and improve transparency in land transactions.

---

## Features

* Secure on-chain land registration
* Transparent ownership verification
* Immutable property records
* Digital transfer of land ownership
* Wallet authentication
* Role-based access for land authorities and users
* Transaction history tracking
* Fast and transparent property validation

---

## Problem Statement

Traditional land registry systems often face challenges such as:

* Document forgery
* Multiple ownership claims
* Slow verification processes
* Lack of transparency
* Centralized data manipulation

BlockPlot addresses these issues through decentralized and verifiable record management.

---

## How It Works

1. A land authority registers a property on-chain.
2. Ownership details are linked to the owner's wallet address.
3. Users can verify land authenticity publicly.
4. Ownership transfers are recorded as blockchain transactions.
5. Every update remains transparent and immutable.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/blockplot.git
```

Move into the project directory:

```bash
cd blockplot
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
